Wie entsteht dieser Baum – und warum genau so?

Der Baum wird nicht gezeichnet, sondern beim Trainieren Schritt für Schritt berechnet. An jeder Stelle prüft der Code alle noch verfügbaren Spalten: Wie viele Fälle würde man richtig vorhersagen, wenn man nach dieser Spalte aufteilt und pro Gruppe einfach die Mehrheitsklasse rät? Die Spalte mit den meisten Treffern wird zur nächsten Frage. Das ist die "simple Abzählung" anstelle einer Informationsgewinn-Formel.
