So ersetzt NumPy die Schleifen

Die versteckte Schicht deines XOR-Netzes besteht aus zwei Neuronen. Jedes Neuron erhält dieselben zwei Eingaben. NumPy berechnet beide gewichteten Summen gleichzeitig mit gewichte_matrix @ eingaben.

2. Versteckte Schicht

Die Matrix hat eine Zeile je Neuron. Jede Zeile enthält dessen Gewichte.

Die Aktivierung ist exakt wie im Code: summe > schwellenwert. Bei Gleichheit ist die Ausgabe 0.

3. Die Matrixmultiplikation, Schritt für Schritt

Was die Schleifen tun

für jedes Neuron: summe = 0 für jede Eingabe: summe += eingabe × gewicht ausgabe = summe > schwellenwert

Was @ tut

summen = gewichte_matrix @ eingaben ausgaben = (summen > schwellenwerte).astype(int)

Das Ergebnis der Matrixmultiplikation ist ein Vektor: eine Summe pro Zeile bzw. pro Neuron.
